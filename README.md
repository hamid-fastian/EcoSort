# 🌱 EcoSort – Smart Waste Management System

**EcoSort** is a C++-based Data Structures and Algorithms project that simulates a smart waste management system. It focuses on waste classification, collection request management, and efficient route planning using fundamental data structures.

## 🎯 Project Objectives

- Simulate a smart waste management system.
- Manage waste collection requests efficiently.
- Implement different data structures to solve real-world management problems.
- Explore priority-based processing and route optimization.
- Apply object-oriented programming and problem-solving concepts in C++.

## 📌 Project Modules

### 1. Queue Module

Manages pending waste collection requests using a linked-list-based FIFO queue.

Each request contains:

- Request ID
- Bin ID
- Location ID

Implemented operations include:

- Enqueue
- Dequeue
- Front
- IsEmpty
- Display
- Size

### 2. Circular Linked List

Responsible for managing data through circular linked-list operations.

### 3. Heap

Designed for priority-based processing of collection requests.

### 4. Graph

Designed to represent locations and support route-planning operations.

### 5. Hash Table

Designed to provide efficient data storage and retrieval.
